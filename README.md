# Sale Out Dashboard

Private dashboard for CHAOSUA Modern Trade Sale Out.

## Contents

- `index.html` — dashboard UI
- `data.json` — aggregated dashboard data exported from DuckDB

## Metrics

- Makro: Qty EA × RSP
- Lotus's: source Sale Out value
- Monthly sales
- Category
- Lotus's Store Format
- Channel and year filters

## Data policy

This repository is private. Raw files, DuckDB databases, master workbooks, credentials, and staging files are excluded from Git.
